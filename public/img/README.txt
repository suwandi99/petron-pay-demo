PUT THE PETRON LOGO HERE

Save the official Petron logo (from Petron Malaysia's brand assets, or the logo file your
Adyen account team received from them) in this folder as ONE of:

    petron-logo.svg   (preferred)
    petron-logo.png   (transparent or white background, about 300 px wide or more)

The app shows it automatically in the top bar. If neither file exists, the app falls back to a
plain placeholder and everything else still works.

On GitHub: open the "public" folder -> "img" folder -> Add file -> Upload files -> Commit changes.
